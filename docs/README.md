# Sensum Dashboard Documentation Index

## Goal system — required reading

Before creating, changing, scoring, completing, or displaying any progression goal:

1. Read `GOAL_AUTHORING_SOP.md`.
2. Read the current definitions and findings in `GOAL_REGISTRY_AUDIT.md`.
3. Verify changed game facts against the OSRS Wiki.
4. Update the audit, sources, verification date, and regression checks with the implementation.

Do not use unrelated account progress or route readiness as a fallback goal percentage. Do not treat recommended preparation as completion. If an aspiration has no finite endpoint, make it a roadmap mode or establish a measurable target before implementation.
